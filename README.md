# Интеллектуальный модуль выбора алгоритма сортировки

## Состав проекта
- `main.py` — весь исходный код: пять алгоритмов сортировки, профилирование, автоматический выбор, пользовательский ввод и тесты.
- `README.md` — инструкция по запуску.
- `individual_report_template.md` — шаблон индивидуального отчёта.

## Требования и зависимости
Python 3.10 или новее. Внешние библиотеки не требуются. Используются стандартные модули `random`, `time`, `sys`, `enum`, `dataclasses`.

## Запуск
В терминале перейдите в папку с `main.py`.

- Интерактивный режим: `python3 main.py` (Windows: `py main.py`)
- Короткая демонстрация: `python3 main.py demo`
- Автоматические тесты: `python3 main.py tests`
- Сортировка чисел из файла: `python3 main.py file data.txt`

Файл `data.txt` должен содержать числа, разделённые пробелами, запятыми, точками с запятой или переводами строк.

## Что делает программа
1. Анализирует размер, долю уникальных значений, упорядоченность и диапазон чисел.
2. Исключает неподходящие алгоритмы из списка кандидатов.
3. Несколько раз измеряет время оставшихся алгоритмов на всей небольшой последовательности или на выборке до 2000 элементов.
4. Выбирает алгоритм с минимальным измеренным временем на этой выборке.
5. Сортирует исходный массив и проверяет результат сравнением с `sorted()`.

## Алгоритмы
- Сортировка вставками.
- Быстрая сортировка с медианой из трёх.
- Сортировка слиянием.
- Пирамидальная сортировка.
- Сортировка подсчётом для целых чисел с ограниченным диапазоном.

## Ограничения
Выбор основан на микрозамерах, поэтому результат зависит от компьютера, нагрузки и состава выборки. Он не гарантирует, что выбранный алгоритм окажется самым быстрым на полном массиве во всех случаях. `sorted()` используется для проверки результата; в сортировке подсчётом также предусмотрен безопасный запасной вариант при чрезмерно большом диапазоне значений.
